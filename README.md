# CodeAlpha Basic Chatbot

## Project Description

This project is a simple rule-based chatbot developed using Python.

The chatbot accepts user input and provides predefined responses based on keywords and conditions.

## Features

* Greets the user
* Responds to "hello", "hi", and "hey"
* Responds to "how are you"
* Provides information about the chatbot
* Handles unknown messages
* Allows the user to exit using "bye", "goodbye", "exit", or "quit"
* Runs continuously until the user exits

## Technologies Used

* Python
* Functions
* if-elif-else statements
* while loop
* String handling
* Console input/output

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```bash
python chatbot.py
```

## Example

```text
You: hello
Bot: Hi! How can I help you?

You: how are you
Bot: I'm fine, thanks! How are you?

You: bye
Bot: Goodbye! Have a nice day!
```
